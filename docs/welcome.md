# 欢迎来到 Macaber 的数字花园

这是新主页发布后的第一篇文档。这里会记录代码、设计，以及构建过程中值得留下来的思考。

## 发布一篇新文档

只需在仓库的 `docs` 目录创建一个 Markdown 文件：

```markdown
---
title: 我的新文章
description: 一句话介绍这篇文章。
date: 2026-09-01
tags: [JavaScript, Notes]
---

# 我的新文章

从这里开始写正文。
```

提交并推送到 `main` 分支后，GitHub Actions 会自动扫描文档、更新主页目录，并为它生成独立页面。

> 文件也可以放在 `docs` 的子目录里，目录结构会被保留在访问地址中。

## Markdown 支持

当前支持常用的标题、段落、列表、引用、链接、图片、行内代码和代码块。整个构建过程不依赖第三方包，轻量而且稳定。

- 专注内容，不用手动维护目录
- 静态页面，加载快速
- 自动适配桌面与移动设备

欢迎常来看看。
